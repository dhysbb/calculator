# calculator

Требуется написать программу эмулирующую работу устройства калькулятор.Пред-

полагается, что калькулятор обладает некоторой ограниченной внутренней памятью для хранения одного числа:

pегистр result некоторой фиксированной битности. Числа, которые вычисляются в процессе работы калькуля-

тором, как раз хранятся данном регистре. В начальный момент работы внутренняя память калькулятора ини-

циализирована значением 0. В процессе работы данное значение меняется при помощи операций калькулятора и

входных данных, вводимых пользователем. В процессе работы с калькулятором в момент выполнения операции

разрядность регистра может быть переполнена. В этом случае калькулятор как устройство выдаёт ошибку.

Программа эмулятор: будет считывать со стандартного потока ввода числа с которыми нужно производить

операции; затем совершать операцию, если её возможно совершить: не будет переполнения и деления на ноль;

затем, по концу потока ввода или поспециальной командеfinish будет выдавать ответ встандартный потоквывода.

Ввод чисел эмулятору калькулятора (в дальнейшем калькулятор) предполагается производить в различных

системах счисления. Вывод чисел так же в различных системах счисления. В случае, когда калькулятор печатает

числа с плавающей точкой – задаётся точность, с которой должен быть выведен ответ. Точность понимается так:

оставшаяся после вывода очередных цифр дробная часть не должна по модулю превосходить заданного параметра

точности.
